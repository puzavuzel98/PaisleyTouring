# Paisley Touring website

A responsive, static website concept based on the handwritten project notes: a free/open-access guide to historical places around Paisley, designed for students, newcomers and people who want to explore local stories on foot.

## Files
- `index.html` — website content and page structure
- `styles.css` — responsive visual design
- `script.js` — place search, category filters, mobile navigation and current year

## Run it
Open `index.html` in a modern browser. No build step or framework is required. An internet connection is needed for the remote Google Fonts and image assets.

## Included
- Hero section and project introduction
- Ten place cards with story summaries, visitor-information links and full-width photography
- Search and category filters
- Suggested walking-tour order
- Nearby café search and local tips
- Responsive mobile navigation
- Keyboard skip link and reduced-motion support

## Before submitting or publishing
1. Verify each site's current opening times, access arrangements, and the accuracy of the descriptions.
2. Replace the sample remote photography with images you have permission to use, and add image credits. Some current image URLs are atmospheric placeholders, not guaranteed photographs of the named Paisley locations.
3. Confirm the route and walking distances on a map.
4. Add the names of your project team and the sources used for historical facts.
5. Keep the site open-access and free to use as described in the project brief.
